## Acceptance rule

A requirement moves out of development only after explicit user acceptance is recorded for that requirement and version. Passing a test or publishing a release is not sufficient. Until then, retain its implementation evidence and any unresolved subpoints. Historical reviews are supporting records, not a second acceptance list.
