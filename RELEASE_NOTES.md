# CartelDesk 1.2.0

Download the Windows ZIP, extract it completely, and run `CartelDesk.exe`. Keep its licenses folder. Existing users should retain their local configuration before replacing their application folder.

This update adds map-search suggestions, fixes shared fog masking for map plans and transfers, and strengthens handling of oversized, stalled or unexpected service responses. The portable runtime is bundled inside the executable.

Ten Windows package checks passed, including startup/shutdown, QR decoding, runtime integrity and the desktop interface test. These checks do not certify every display or game-data entry.

Player pairing is a preview: inventory synchronization and full-save transfer are unavailable. Positions and production information reflect saved state. Planning does not perform actions in DDS2. Unknown reference data stays unknown.

See the [README](README.md) for map searches, recipes, shopping lists, phone access and Steam overlay setup.
