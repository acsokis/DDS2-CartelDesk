# DDS2 CartelDesk v1.0.0

First public Windows x64 release: native Qt 6.12 Widgets desktop, desktop web and portrait phone companion.

- Managed Start / Stop and read-only DDS2 save loading.
- 187 documented in-game recipes, production equipment and stock/capacity planning.
- Discovery-based fog-of-war on native and web maps.
- Saved logistics and distributor data; CSV and ZIP exports.
- Eleven languages with system/browser defaults.
- Credits, build description and author profiles.

Download **DDS2-CartelDesk-v1.0.0-Windows-x64.zip**, extract all files, then run **CartelDesk.exe**. The separate **Media.zip** contains screenshots, social covers and Steam/LinkedIn/Nexus posting drafts. **SHA256SUMS.txt** provides download checksums.

35 Windows automated checks passed; portrait browser captures had no JavaScript errors or horizontal overflow. Physical-phone touch testing has not been performed. Unknown data stays unknown; map exploration is based on saved known places, not the game's pixel mask. Transfer lines are straight-line estimates.

The public repository contains documentation/media only. Native application source remains private. The Qt source archive in the Windows ZIP is third-party corresponding source required for redistribution.
