DDS2 CartelDesk — standalone Windows planning utility

A free, unofficial companion for Drug Dealer Simulator 2. It reads local saves and provides a native Windows command desk plus a portrait phone web interface.

Features
- Recipe ingredients, production equipment and known acquisition locations.
- Separate owned inventory and acquisition sources; unknown prices and stock stay unknown.
- Planner add / remove, quantity editing, named lists, favorites, filters and reset.
- Game exploration from read-only FOW_Target.exr; fog toggle and optional LAN exploration sharing.
- Map markers, persistent legend, result count, empty-state guidance and cached / debounced rendering.
- Red triangle pings: sets, multi-selection, bulk add / remove, adjustable 1–86400 second lifetime and manual straight-line routes.
- Local QR code for phone access, 11 languages, resizable desktop and optional animation.
- Filtered CSV and table ZIP export.

Installation
1. Download and extract the complete Windows ZIP to a writable folder.
2. Run CartelDesk.exe. Keep runtime, web and licenses alongside it.
3. Start the service and select a campaign. The default folder is %LOCALAPPDATA%\DrugDealerSimulator2\Saved\SaveGames\Cartels.
4. For phone access, enable LAN companion, choose the shared Wi-Fi address and scan the QR code. Use the included private-network firewall helper if needed.

Requirements: Windows 11 x64. No compiler, Qt SDK, Node.js or Python is required to run the package. This is a manual-download utility; no Vortex deployment extension or game-file replacement is included.

Limits: saves are read only; no gameplay automation. Route lines are straight-line aids. Missing / unsupported exploration masks keep terrain covered until fog is switched off. Physical-phone and game-session FPS verification are not yet complete. Back up your campaign through your normal process.
