DDS2 CartelDesk v1.1.1 — a local desktop and phone planning companion for Drug Dealer Simulator 2.

I built a C17 backend and C++17 Qt desktop app with a responsive browser companion. The workflow combines read-only campaign data, 187 recipe references, production equipment, owned stock and independent acquisition sources.

This update replaces inferred exploration with the game's FOW_Target.exr mask, adds optional fog sharing and external map pings, and improves map movement and typed filters. Planner lists support quantities, save / load, favorites, filtering and removal. A local QR code connects the phone interface.

The app is free to download. Public distribution contains the runtime, documentation and screenshots; application source remains private. Known and unknown data remain distinct. No gameplay automation or full-save network import is included.

I'm available to discuss companion tools, desktop interfaces and data-driven planning utilities for other games.
